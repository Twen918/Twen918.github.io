playtest-triage

[python][claude api][pytest + ci]

A CLI that turns raw playtest notes into a structured QA report: classifies each note (bug / balance / UX), assigns severity, merges near-duplicate reports, and renders a prioritized markdown summary. Built after shipping Desperation, when sorting feedback by hand took longer than fixing some of the bugs.
